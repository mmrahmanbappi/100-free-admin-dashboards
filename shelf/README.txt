SHELF - Commerce & Sales Dashboard Template
===========================================

This template is free to use for personal and commercial projects under the MIT license.
It is part of 100 Free Admin Dashboards: https://github.com/mmrahmanbappi/100-free-admin-dashboards

QUICK START
  1. Unzip the folder.
  2. Open index.html in any browser. That is the entire setup.
  There is no build step, no npm install and no server requirement.
  Every asset is local, so the template works offline.

FULL DOCUMENTATION
  Open documentation/index.html in a browser. It covers:
    - the folder structure
    - re-skinning from one block of CSS custom properties, with three
      ready-made alternate colour schemes
    - replacing the demo data with your own
    - the data attributes that build each page
    - the JavaScript API
    - accessibility and browser support

WHAT IS INCLUDED
  36 HTML pages, one stylesheet, one data file, one script,
  self-hosted fonts, a local copy of Chart.js, this readme,
  a changelog and a licence and credits file.
