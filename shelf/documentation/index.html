Shelf

A commerce and sales dashboard template. 36 pages, light and dark, no build step, no framework, no internet connection required.

HTML, CSS and vanilla JavaScript Light and dark themes Works offline Responsive to 390px

1. Getting started

Unzip the folder and open index.html in a browser. That is the whole setup. There is no npm install, no bundler and no server requirement, and every asset is local so the template works with no internet connection.

To publish, upload the folder to any static host. To use it inside an application, copy assets/ and treat each HTML page as a layout reference.

3. Re-skinning

Every colour, radius, shadow and font in the template resolves through a custom property. Open assets/css/shelf.css and edit the two blocks at the top: :root for light and [data-theme="dark"] for dark. Nothing below those blocks contains a colour literal, so one edit re-skins all 36 pages including the charts, which read their colours from the computed styles at runtime.

Three alternate schemes

Paste any of these over the accent and series values in :root.

/* Ink blue */
--accent:#1F4B99; --accent-hover:#173A78; --accent-soft:#E6ECF7;
--series-1:#1F4B99; --series-2:#A8751A; --series-3:#2E7E86; --series-4:#B23A2B;

/* Plum */
--accent:#6B2D5C; --accent-hover:#57244B; --accent-soft:#F2E7EF;
--series-1:#6B2D5C; --series-2:#2E7E86; --series-3:#A8751A; --series-4:#B23A2B;

/* Charcoal, accent used sparingly */
--accent:#26251F; --accent-hover:#111110; --accent-soft:#EDEBE4;
--series-1:#26251F; --series-2:#0F6B4F; --series-3:#A8751A; --series-4:#B23A2B;

Fonts

Change --font and --mono in :root. If you swap to a font you host yourself, add the @font-face rules to assets/css/fonts.css and drop the files into assets/fonts/. If you prefer Google Fonts over self-hosting, replace the fonts.css link in each page head with the Google stylesheet link.

Theme behaviour

The theme is set with a data-theme attribute on <html> and stored in localStorage under shelf.theme. A small inline script in every page head applies the stored value before first paint so there is no flash. To ship dark as the default, change data-theme="light" to data-theme="dark" in the page templates.

4. Replacing the demo data

Every figure on every page comes from assets/js/shelf-data.js. Nothing is hard coded into the HTML. Replace the contents of that file, keep the key names, and all 36 pages follow.

window.SHELF_DATA = {
  settings:  { store, domain, currency, timezone, user },
  labels30:  [ "21 Aug", … ],          // x axis labels
  metrics:   { revenue:{ label, value, delta, unit, series, invert? }, … },
  definitions:{ revenue:"…", … },       // tooltip text on metric labels
  orders:[], products:[], customers:[], channels:[], inventory:[], …
};

Metric unit is one of money, count, rate or pp. Set invert:true on any metric where a fall is good, such as refund rate, and the delta colours itself correctly without you changing the sign.

To wire it to a real backend, fetch your data, shape it into the same object, assign it to window.SHELF_DATA before shelf.js loads, and delete the demo file.

5. Building a page

Pages are declarative. You write markup with data attributes and the script fills it in.

AttributeWhat it renders
data-kpis="revenue,orders"A row of KPI cards with deltas and sparklines
data-chart="line|metric:revenue"A chart. Kinds: line, area, bar, hbar, donut
data-chart="donut|list:channels:name:share:4"A chart from any collection
data-compareAdds a dashed previous-period series
data-table="orders" data-cols='[…]'A full table from a collection
data-pickAdds row checkboxes and the floating bulk bar
data-filter-key="status"Lets filter chips filter rows by that field
data-bars="channels:name:revenue:4"A ranked bar list
data-feed, data-live-feedActivity feed, optionally live
data-funnel, data-cohortCheckout funnel, retention grid
data-act="modal" data-val="m-id"Opens that modal. Also drawer, toast, copy, print, busy

Table columns

data-cols='[
  {"t":"Order","k":"id","f":"link","href":"order-detail.html"},
  {"t":"Customer","k":"customer","f":"person"},
  {"t":"Total","k":"total","n":1,"f":"money"},
  {"t":"Status","k":"status","f":"pill","tone":"tone"}
]'

t is the heading, k the key in the data row, n right-aligns and uses the mono face, and f picks a formatter: product, person, link, num, money, pct, pill, meter, stars, delta, strong, sku, score.

7. Accessibility

  • Every interactive element is a real button or link, never a clickable div.
  • Visible focus rings on everything, and they are never removed.
  • Modals and drawers trap focus and return it to the trigger on close.
  • Escape closes, in order: command palette, modal or drawer, popover, mobile navigation.
  • Tables carry aria-sort, the live region is aria-live="polite".
  • Colour never carries meaning alone: deltas have arrows, statuses have text labels.
  • prefers-reduced-motion is honoured.

8. Browser support

Current versions of Chrome, Edge, Firefox and Safari, desktop and mobile. The layout uses CSS logical properties throughout, so setting dir="rtl" on <html> mirrors the whole interface with no second stylesheet.
