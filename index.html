FAQ

Questions people ask

Are these dashboards free for business use?

Yes. Every dashboard uses the MIT license, so you can use it in personal, client and commercial projects.

Do they need a framework or a build step?

No. Each dashboard is plain HTML, CSS and JavaScript. Open a page in a browser and it works.

How many pages does each dashboard have?

Most have 34 pages: an overview, lists, details, forms, a calendar, reports, settings, login and more.

Do they connect to real data?

No. They use sample data so you can see every page. Replace the sample data with your own API when you build your app.
