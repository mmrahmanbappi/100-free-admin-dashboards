Assets NOT included
-------------------
No photography, no icon font and no third party icon set is used. Every icon is
inline SVG authored for this template. Patient and clinician avatars are
generated from initials in CSS, so there is nothing to license and nothing to
replace.

Demo content and intended use
-----------------------------
Every patient name, MRN, clinician, diagnosis, observation, medication and
result in the demo data is invented for demonstration. Any resemblance to a real
person is coincidental.

This is a user interface template. It is not a medical device, it performs no
clinical calculation, and it must not be used to make clinical decisions. The
reference ranges and escalation thresholds shown in the demo data are
illustrative only. Anyone deploying this interface in a clinical setting is
responsible for their own clinical safety case, validation, and compliance with
the medical device and data protection rules of their jurisdiction.
